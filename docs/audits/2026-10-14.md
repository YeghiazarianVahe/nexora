## Requires decision
1. **N18 helper trust bootstrap** (human checkpoint): SMB install with hard-coded reviewed hash, Authenticode signing with pinned thumbprint, or out-of-band key fingerprint.
2. **N32 replay/connection binding** (human checkpoint: nonce/signature).
3. **N22 script approval:** should creating or editing a `script.run` script need a second person? (Hash snapshot is a patch regardless.)
4. **N23:** should Viewers run any remote job at all?
5. **N33:** should single-target Low-risk actions skip confirmation at all?
6. **N21:** does read-only `verify-helpers.ps1` against `\\wks-NN\C$` count as touching a live share? Should deploy `-Server` be allow-listed (N41)?
7. **N43:** re-check AD group membership (periodic or at claims time, auto-revoke)? May a SuperAdmin direct-add bypass the group?
8. **N44:** accept and document fleet-wide DCOM rights, or scope them (needs GPO, conflicts with C3)?
9. **N57:** separate migration owner and a runtime role limited to INSERT/SELECT on the audit table?
10. **N71 / N75:** drive-serial visibility policy; strict three-colour palette vs warn/danger colours.
